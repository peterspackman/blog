Utilities

Chemistry tools that run in your browser. Everything runs locally with WebAssembly, so nothing gets uploaded anywhere.

Quantum chemistry

Wavefunction calculator

HF and DFT with OCC, plus orbitals, geometry optimisations and frequencies.

Elastic tensor analysis

Paste a 6×6 stiffness matrix and see how the moduli vary with direction.

Simulation

LAMMPS in the browser

Run an input script, plot the thermo output, watch the trajectory.

Trajectory viewer

Play back optimisation paths and MD trajectories from multi-frame XYZ files, with unit cells.

Molecules

SMILES viewer

Draw 2D structures from SMILES strings with RDKit.js.

Infinite molecules

Generate random valid molecules from SELFIES strings and browse them as a scrolling grid.

Built with OCC for quantum chemistry, RDKit.js for cheminformatics, LAMMPS for molecular dynamics and NGL for 3D structures.
